-------------------
1. Unzip this folder.
2. Open index.html in any modern browser (Chrome, Safari, Firefox, Edge).
3. Everything works offline except the images (they load from Unsplash) and the WhatsApp links.

HOW TO PUBLISH FREE ON GITHUB PAGES
-----------------------------------
1. Create a free GitHub account at github.com (if you don’t have one).
2. Click “+” → “New repository”.
3. Name it e.g. outshine-mobile-carwash-demo. Make it Public. Do NOT add a README.
4. Click “Create repository”.
5. Click “uploading an existing file”.
6. Drag all three files (index.html, style.css, script.js) into the page.
7. Scroll down → Commit changes.
8. Go to Settings → Pages (left menu).
9. Under Source: Deploy from a branch → Branch: main → Folder: / (root) → Save.
10. Wait 1–2 minutes. Your live demo link will appear:
    https://YOUR-USERNAME.github.io/outshine-mobile-carwash-demo/
